RNZW SKINS - PRONTO PARA VERCEL

PUBLICAR (sem instalar nada):
1. Extraia este arquivo ZIP.
2. Acesse https://vercel.com/new e importe a pasta RNZW-SKINS-VERCEL usando um repositório Git ou a CLI da Vercel.
3. Projeto estático: Framework Preset = Other, sem build command, Output Directory padrão (vazio).
4. Clique em Deploy.

OU via terminal, na pasta extraída:
   npx vercel --prod

O index.html está na raiz da pasta.
Sem Node, npm install ou banco de dados obrigatórios.
